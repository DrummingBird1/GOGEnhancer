# Chrome Web Store — descriptions in other languages

Condensed store descriptions for the languages the extension's interface comes in. In the
Developer Dashboard open **Store listing**, pick the language from the language selector,
and paste the **summary** and the **description** below. The English and Hebrew texts are in
`STORE_LISTING.md` (the full versions); these are shorter on purpose and cover the same
facts as the 4.5.0 build: 24 currencies, nine interface languages, nothing sent except the
destinations listed.

They were written without review by native speakers. Read the one you will publish before
pasting it, and fix anything that reads oddly.

If the Edge Add-ons dashboard asks for a language, the same texts apply.
