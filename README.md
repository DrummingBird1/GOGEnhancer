An unofficial third-party extension for GOG.com — live currency conversion, price-history tracking, cross-store price comparison, personal tags, a full visual upgrade, Hebrew + RTL — all without Google Fonts and without analytics.

> **Disclaimer:** This is an unofficial third-party extension. It is not affiliated with, endorsed by, or sponsored by GOG sp. z o.o. or CD Projekt S.A. The "GOG" name is used nominatively to describe the storefront the extension works with.

## ✨ Feature overview

### Architecture
- **Unified storage layer** — preferences in `storage.sync` (lightweight, synced across devices), heavier data (tags, history, caches) in `storage.local`. Nothing spills past either quota.
- **Settings versioning + migration** — upgrading from v1 automatically moves tags and notes from sync to local.
- **System fonts only** — zero dependency on Google Fonts, no remote code, no analytics.
- **One network layer** (`lib/net.js`) — every request the extension makes goes through it: an allow-list of five hosts, no cookies, no referrer, a timeout, and a local log of host + path (never the query) that the Advanced Options page shows. A test fails the build if a permission or host changes without the privacy documents saying so.
- **One site adapter** (`content/gog-dom.js`) — every lookup of gog.com's markup (cards, prices, title, panel position) tries several strategies, so a redesign degrades gracefully instead of silently breaking features. "Check this page" in Advanced Options shows which lookups still work.
- **Focused `MutationObserver`** on the page content with debouncing; header churn is filtered out and a replaced `<main>` is picked up.
- **Each feature runs in isolation** — if one lookup breaks after a site change, that feature switches off and the rest keep working; "Check this page" lists what failed.
- **Learns only from pages you open** — ownership, ratings, languages and price facts are read from pages you visit yourself and stored locally. The extension fetches nothing extra to build them.

### Features
- 💱 **Live currency rates** — fetched automatically from `api.frankfurter.app` every 12 hours. Editable manually.
- 📈 **Price tracking** — every visit to a game page records a snapshot. A stats panel on the game page shows current / all-time low / average, plus a "Worth waiting?" verdict.
- 🔍 **Compare on IsThereAnyDeal** — a button on the game page searches for the same title on Steam / Epic / Humble / Fanatical.
- 🏷️ **Full tag dashboard** — a separate page with search, filtering, a count per tag, and CSV export. Autocomplete for existing tags.
- 🔔 **Wishlist sale alerts + deals** — a badge on the toolbar icon counts discounted wishlist items; the popup shows your top 3 tracked price drops.
- 🛡️ **DRM-free banner** — a solid banner with a shield icon and a gradient "GOG+" pill.
- 🎨 **Card visual upgrade** — card-aware: "Good Old Game" gets a subtle CRT effect + gold halo; Cyberpunk/Witcher titles get a cyan/magenta neon underglow.
- 🪟 **Styled tooltips** — replaces the browser's default tooltip, with headings, rich content, automatic positioning.
- 📋 **Dynamic mods list** — scraped automatically from `gog.com/en/mods` every 24 hours.
- 🌍 **Automatic on-page currency detection** — if GOG already shows EUR (EU users), the extension doesn't convert again.
- 🎯 **Proper RTL** — using `inline-start`/`end` instead of `left`/`right`, and `unicode-bidi: isolate` for prices.
- ⌨️ **Keyboard shortcuts** — `Alt+G` opens the popup, `Alt+Shift+G` toggles on/off, `Alt+Shift+H` toggles Hebrew; `Ctrl/Cmd+K` opens a command palette for everything else.
- 🧙 **Onboarding wizard** — 4 steps (currency, region, features, theme), opens automatically on first install.
- ☁️ **Sync across devices through a folder you choose** (Dropbox, OneDrive, Google Drive, Syncthing…) — merges tags, notes, status, purchases, alerts and price history per record, optionally encrypted. Nothing of ours is in the middle. Chrome / Edge / Brave.
- 🔎 **Address-bar library search** — type `gog` + Tab, then a game name, `tag:rpg` or `status:backlog`.
- 🎨 **Native theme** — samples gog.com's own colors and font so injected UI blends in with whatever the site looks like.
- ⌨️ **Keyboard navigation** (opt-in) — `J`/`K` move between games on a listing, `T` tags the focused one.
- 📅 **Calendar files (`.ics`)** for refund deadlines and for the release dates of wishlisted games, and 📝 **Markdown / Obsidian / CSV exports** from the tag dashboard — all built on your device.
- 🌍 **Seven interface languages** — the tag dashboard, Advanced Options, popup and first-run wizard in English, Hebrew (right-to-left), Russian, Polish, German, French and Spanish. What you write yourself (tag names, notes) is never translated.
- 🔒 **Privacy dashboard** in Advanced Options — every address the extension contacted, what it keeps on your device and how much, the extra site access Chrome has granted it, and one-click clearing.
- 🩺 **Failure report** — when a feature stops working after a site change, the popup offers a one-click report with no web addresses and no personal data ("Report on GitHub" only opens a page with it filled in).
- 🖥️ **System check** on game pages — compares a game's RAM requirement with what your browser reports (RAM only; browsers can't see your CPU or GPU). Type your own OS / processor / graphics card in Advanced Options and those are compared as plain text — an estimate.

#### Deals & pricing (v4)
- 💸 **"Is this discount real?"** — compares the base price with GOG's own lowest-in-30-days and your tracked history; ⏳ **offer countdown** on the game page, on cards and in the digest.
- **Price per hour of play**, **price in several currencies** at once, a per-game **sale rhythm**, a **comparison chart** for 2–3 games, **"how much I saved"** totals, and national **VAT presets** (DE, FR, ES, IT, NL, RU).

#### Wishlist & catalog (v4)
- 💖 **Smart wishlist** — sort by discount / distance from the low / converted price / date added, "near the low" and "ending soon" filters, a live total, grouping by tag or status, export to CSV / Markdown / `.ics`.
- 🗂️ **Catalog tools** — a bar above the grid: dim or hide games you own, **not interested** (restorable), local sort of the page, compact / list density, saved filter presets, bulk tag/track, side-by-side comparison.
- ♾️ **Endless scrolling** (opt-in, off by default) — when you reach the end of a catalog page, the next page is added below it, from GOG's own catalog API (`catalog.gog.com`, the same call the site makes).

#### Game page & library (v4)
- 🎮 **Language check**, **what changed since your last visit**, review filter, **similar games you own**, **what a pack really contains** (read from the bundle's own page, or from GOG's product API once per game page — only a numeric id is sent) with a heads-up when it overlaps what you own, "open in" links to Steam / IsThereAnyDeal / PCGamingWiki, and the `W` / `N` / `A` shortcuts.
- 📚 **Learns your library as you browse** (from the site's own "IN LIBRARY" label), which powers hide-owned, real library statistics, a weighted backlog roulette, a monthly "games to finish" goal, and **Wrapped / collector cards** you can save as PNG.
- 📝 **Note version history**, an **Obsidian vault** export (`.zip`), and CSV / line exports for **Notion, Google Sheets and Trello**.
- 🏆 **36 achievements** in three tiers (a few hidden), a **streak** of days you've browsed and three **monthly challenges** — all local.
- ♿ **A dashboard you can use from the keyboard** — a skip link, tags reordered with `Alt`+`↑`/`↓`, menus and dialogs that hold focus, and spoken (screen-reader) announcements of changes.

#### Sync, notifications & look (v4)
- 🔄 **Automatic folder sync** (dashboard open + every 30 minutes, when the browser still remembers the folder permission and the file isn't passphrase-encrypted), a conflicts list, and dated backups kept in the folder.
- 🔔 **Quiet hours**, a **one-summary-a-day** mode, thresholds, **alerts by tag**, an optional **season radar**, a richer weekly digest you can save as a web page, a wishlist card you can save as a PNG — and an optional **webhook to an address you own** (see the permissions table).
- 🎨 **Fold / dock / reorder** the game panel, **calm mode**, a one-click **plain look**, colour-vision palettes, text-size scaling, settings profiles, and a short **tour** after the update.

### Visual upgrade module
Enabled via the "Design injection" toggle in the popup. When on:
- Prices everywhere use a mono font (`ui-monospace` / Cascadia / JetBrains) with tabular numerals.
- Era-aware cards: scan-lines for classics, neon glow for cyberpunk-era titles.
- Subtle depth/shadows, an ambient gradient background, micro-interactions on hover.
- The "Good Old Game" pill gets a metallic gold gradient instead of a flat purple.
- Skeleton loaders with a shimmer animation instead of exposed `{{ product.title }}` placeholders.
- Clean layout: hides expired promos from past years.
- Nine themes (Neon, Classic GOG, CRT Green, Sunset, Light, High contrast, Custom, Auto, Native) — Auto follows your system's light/dark preference; Native follows gog.com's own look.

### Honest privacy
- **Only five domains** ever receive network requests — and every request is listed in Advanced Options (Privacy & transparency):
  1. `www.gog.com` — to read page content and inject UI, and the public mods list once a day.
  2. `api.frankfurter.app` — for currency rates (no API key, no tracking).
  3. `www.cheapshark.com` — the optional price-comparison table on game pages (free, keyless; turn it off in the popup).
  4. `api.gog.com` — GOG's own product API, asked once per game page which games a pack contains (only its numeric id is sent; on by default, switch it off under *Catalog, wishlist & library*).
  5. `catalog.gog.com` — GOG's own catalog API, used only if you turn on endless scrolling (off by default).

  The last two have no entry in the permissions table because they are called from the page under GOG's own cross-origin rules — the same calls the site makes — so Chrome shows no extra install warning for them.
- **Folder sync makes no network request of its own** — it reads and writes one file in a folder you pick; your own cloud client does any uploading.
- **The webhook is optional and yours** — nothing is requested at install. If you type your own `https://` address in Advanced Options, the browser asks you once to allow that single origin; only the notification text is sent to it, and the address never leaves your device through exports or sync.
- **Zero analytics, zero gtag, zero Google Fonts.**
- **Tags, notes, and history live on your device** via `chrome.storage.local`. Nothing leaves it.
- **Open source** — every line of code is in this repository.

## 🚀 Installation

1. Download `gog-enhancer-webstore.zip` from the [Releases](https://github.com/DrummingBird1/GOGEnhancer/releases) page and extract it anywhere (or, if you cloned the repo, use the `extension/` folder directly).
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (top-right corner).
4. Click **Load unpacked** and select the folder you extracted (or `extension/`).
5. The onboarding wizard opens automatically in a new tab. Go through the steps.
6. Browse to [gog.com](https://www.gog.com) — the extension is active.

## ⚙️ Permissions explained

| Permission | Why |
|---|---|
| `storage` | Save preferences, tags, and history |
| `activeTab` | Reload the active tab when you click "Reload" in the popup |
| `alarms` | Scheduling background FX/mods/wishlist refreshes |
| `notifications` | Opt-in only — desktop alerts for refund windows and wishlist deals |
| Host: `www.gog.com` | Inject UI into GOG pages |
| Host: `api.frankfurter.app` | Fetch currency rates |
| Host: `www.cheapshark.com` | Optional cross-store price comparison on game pages |
| Optional host: any `https://` origin | **Never granted at install.** Requested at runtime, for one origin only, if you enter your own webhook address in Advanced Options; only notification text is sent to it |

No permission is needed for folder sync (you grant one folder at a time, from a click) or for the address-bar keyword.

## 🛠️ Known limitations

- **Redesign adaptation was checked against the live site, but gog.com keeps changing** — the home page, catalog and game page were inspected and exercised end to end (logged out) on 2026-10-02; account pages (wishlist, library, cart) need a login and were only inspected structurally. The site currently mixes two generations of markup, so expect more churn. Use *Advanced Options → Check this page* if something stops working after a gog.com update.
- **Folder sync resolves conflicts by each device's clock** — last edit wins per record (the overwritten records are listed on the options page), so badly skewed clocks can pick the wrong winner. It needs the File System Access API (Chrome, Edge, Brave; not Firefox), and folder access has to be re-granted from the options page now and then. The background job can't ask for permission or a passphrase, so it silently skips until you open the dashboard when either is missing. It has been tested against a local folder, not against a real cloud-sync client.
- **Not everything in v4 could be verified against the real site** — features that depend on being logged in (wishlist rows, library ownership, which games a pack overlaps) were built from recorded page *structure* and unit/end-to-end tests, not exercised with a live account. The webhook has not been tried against a live endpoint, and Firefox is untested.
- **Endless scrolling needs GOG's catalog API to stay as it is** — it continues only a list it can match to the one on screen, using the query the site itself transferred to the page. If GOG restricts that API the feature simply stops appending; nothing else is affected. Release-date calendar entries only exist for games whose page you have opened (the wishlist itself only shows a year).
- **The translations are unreviewed** — the six non-English interface languages were written without a native-speaker review; a Hebrew-first project, so Hebrew has had the most attention. Strings that appear only after an action (some dialogs and error messages) are covered, but anything new that has no translation yet simply stays English.
- **Not built:** a cart / giveaway detector, a side panel and context menus (each would need a new permission).
- **Mods list scraping** — depends on `gog.com/en/mods` keeping a similar structure. If it regresses, force-refresh via Advanced Options.
- **Wishlist badge counter** — based on a live DOM count taken when you visit `/account/wishlist` (24h TTL). If you haven't visited recently, the badge stays empty until your next visit — the extension icon's tooltip will suggest visiting.
- **Refund timer relies on a manually entered date** — GOG doesn't expose a purchase date through any public DOM, so the 30-day countdown depends on a date you type into the panel. No date typed, no countdown.
- **Genre detection is partially automatic (since v2.6.0)** — Horror/Role-playing/Strategy are read from the real "Genre:" field on a game's own page and cached by slug (`gameGenres`) on first visit. Sci-fi and Indie still rely on matching known game titles by regex — on GOG these appear to sit under the broader "Tags" cloud rather than "Genre:", and that structure hasn't been fully verified. Until a specific game has been visited, all five genre buckets fall back to the regex.
- **Cross-currency conversion always pivots through USD** — if either pair's rate is missing from `rates`, the conversion won't happen. All rates are fetched automatically every 12 hours from frankfurter.app.
- **Wishlist-wide price alerts, Wishlist deals, and Wishlist value only cover games you've visited** — all three rely on `priceHistory`, which is only built by visiting a game's own page. A wishlisted game you've never visited has no data to compare against, so it won't show up in alerts, in the popup's "Wishlist deals," or in the "Wishlist value" stat, even if its price has dropped.
