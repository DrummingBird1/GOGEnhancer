07

Sync across devices

Pick a folder that Dropbox, OneDrive, Google Drive or Syncthing already keeps in sync. GOG Enhancer reads and writes one file in it, gog-enhancer-sync.json, and merges changes from every browser pointed at the same folder. It makes no network request for this — your folder is the whole transport. Tags, notes, play status, purchases, price alerts and price history sync; settings already sync through your browser account. Deletions sync too.

This browser can't pick a folder for sync (it needs the File System Access API — Chrome, Edge and Brave have it).

Privacy & transparency

      

        GOG Enhancer talks to three domains and that's it:
      

      
    
        
  • www.gog.com — to read what's on the page and inject UI.
    • 
        
  • api.frankfurter.app — to fetch USD→EUR/ILS/GBP/PLN/RUB rates (no key, no tracking).
    • 
        
  • www.cheapshark.com — the optional price-comparison table on a game page (only the game's title is sent).
    • 
      

      

        The one other address it can ever contact is a webhook you
        enter under Notification rules — off by default, and the browser asks
        your permission for that one origin. No analytics. No third-party fonts.
        Tags & notes never leave your machine.
