Features

Everything GOG.com is missing

One extension, twelve features, zero accounts to create.

💱

Live currency conversion

Converts prices to ILS, EUR, GBP, PLN, or RUB using rates from a free, public ECB-backed API — full cross-currency conversion, not just USD.

📈

Price history & sale tracking

Every visit records a snapshot. See current vs. all-time-low vs. average on a sparkline, with a banner when a game hits its historic low.

⏱️

Refund window timer

Mark your purchase date and get a live countdown on GOG's 30-day money-back window, with an optional reminder before it closes.

🔎

Compare on IsThereAnyDeal

One click on any game page opens a cross-store price check on Steam, Epic, Humble, and more.

🏷️

Tags, notes & a full dashboard

Private tags and notes per game, with colors, search, drag-to-reorder, and CSV export/import — plus a standalone dashboard for your whole library.

📊

Library year-in-review

Annual stats computed entirely from your local data: games tracked, biggest price drop, most-watched title, refund windows logged.

🕹️

Playing / Backlog / FinishedNEW

Track where you are with each game, separate from tags — set it on the game page or the dashboard, and filter by status.

🔔

Wishlist sale alerts

A toolbar badge counts wishlist deals. Opt in to get notified the moment any tracked game drops off its own peak price.

⌘

Command paletteNEW

Ctrl/Cmd+K opens quick access to every setting, the tag dashboard, and force-refreshes — no more hunting through menus.

🎨

Six visual themes

Neon, Classic GOG, CRT Green, Sunset, Light, and an Auto mode that follows your system's light/dark preference.

א

Hebrew, RTL & 7 languagesNEW

Full Hebrew translation + real RTL layout for GOG.com, plus the extension's own UI in English, Hebrew, Russian, Polish, German, French, or Spanish.

🔒

Privacy-first, always

No analytics, no ads, no remote code. Everything stays on your device except two anonymous calls for exchange rates and mod listings.

Get started

Install it in under a minute

Not on the Chrome Web Store yet — install the unpacked build directly from GitHub.

1

Download & unzip

Grab gog-enhancer-webstore.zip from the latest release and unzip it anywhere.

2

Open extensions

In Chrome, Edge, or Brave, go to chrome://extensions and turn on Developer mode (top right).

3

Load unpacked

Click Load unpacked and select the unzipped folder. An onboarding tab opens automatically — you're done.

Chrome Web Store submission is on the way — this page will switch to a one-click install once it's live.

Trust

Privacy, by construction

Nothing here is a policy promise bolted on after the fact — it's how the extension is built.

  • No analytics, telemetry, or third-party tracking of any kind
  • No ads, ever
  • Tags, notes, and price history never leave your device
  • Only two outbound calls: exchange rates and the public GOG mods list
  • No Google Fonts, no CDNs, no remote code
  • Open source under the MIT license — verifiable end to end
