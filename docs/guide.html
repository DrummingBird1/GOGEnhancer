Guide

How it works & FAQ

GOG Enhancer is an unofficial extension that adds things gog.com doesn't have — currency conversion, price history, tags and notes, a smarter wishlist and catalog, library statistics — on top of the real site. This page explains how it does that, and answers the questions that come up most.

How it works

The extension runs on www.gog.com pages. It reads what the page already shows (cards, prices, the game title, ratings, the "IN LIBRARY" label) and adds its own elements next to it — a converted price, a badge, the insights panel on a game page, a bar above the catalog. It does not log in for you, change your account, or call GOG's account API.

Everything that looks at gog.com's markup goes through a single module, the site adapter, which tries several independent ways to find each thing (the URL, the page's metadata, semantic tags, class names, finally the text shape of a price). When gog.com changes its layout, one way usually still works, so a redesign degrades a feature instead of switching everything off — and each feature runs on its own, so one broken lookup never takes the others with it. Advanced Options → Check this page shows which lookups still work on the page you have open.

What the extension learns — which games you own, ratings, languages, prices, price history — comes only from pages you open yourself, and is stored on your device. It makes no request to build any of it.

What it sends, and where

Five addresses, and no others: www.gog.com (the page you're on, and the public mods list once a day), api.frankfurter.app (exchange rates), www.cheapshark.com (the optional price-comparison table — only the game's title), api.gog.com (once per game page, to see what a pack contains — only its numeric id) and catalog.gog.com (only if you switch on endless scrolling). No cookies, no referrer, no account information. The one other possible destination is a webhook address you type in, off by default. Every request is listed on the Advanced Options page under Privacy & transparency, with what the extension keeps on your device. The full detail is in the privacy policy.

Getting started

  1. Download gog-enhancer-webstore.zip from the latest release and unzip it (or use the store listing once it's live).
  2. In Chrome, Edge or Brave open chrome://extensions, switch on Developer mode and choose Load unpacked.
  3. A short wizard opens: your currency, your region's tax, which features you want, a look. Everything can be changed later.
  4. Open gog.com. Click the toolbar icon (or press Alt+G) for the quick toggles; Advanced opens every setting; Tag dashboard opens your tags, notes, statistics and achievements.

Frequently asked questions

Does it need my GOG login, or can it see my account?

No. It never logs in, never reads your order history and never calls GOG's account API. It knows which games you own only because gog.com itself marks them IN LIBRARY on pages you open while signed in; it remembers that mark locally. Catalog pages can only add to that list — a tile without the mark might just mean you're signed out — and a refunded game is removed only when you open its own page while signed in.

Where is my data, and can I take it with me?

On your device, in the browser's own storage. Preferences (which features are on, your currency) travel with your browser's sync if you use it; tags, notes, price history and everything learned about your library never do. Advanced Options → Your data exports everything as JSON (optionally encrypted with a passphrase) and imports it back; the dashboard exports to CSV, Markdown, an Obsidian vault, a pack file you can share, and more. Reset everything deletes it all.

How do I use it on two computers?

Pick a folder that Dropbox, OneDrive, Google Drive or Syncthing already keeps in sync: Advanced Options → Sync across devices → Choose folder, then do the same in the other browser. The extension reads and writes one file, gog-enhancer-sync.json, and merges changes per record; if both sides changed the same record, the newer edit wins and the overwritten one is listed so you can overrule it. You can encrypt the file with a passphrase, switch on automatic sync and dated backups, and none of it involves a server of ours. It needs a browser with the File System Access API — Chrome, Edge or Brave.

Something stopped working after gog.com changed. What do I do?

Open the page that misbehaves, then Advanced Options → Check this page. It lists which lookups (cards, prices, title, panel position) still find what they need and which strategy found each one — only the page path and public store text, nothing personal. If a feature has failed, the popup also shows a banner with Copy report and Report on GitHub; the report contains no web addresses or personal data, and "Report on GitHub" only opens a page with it filled in — you decide whether to send it.

Prices aren't being converted.

Check that a target currency is chosen in the popup and that the converter is on. On a page where GOG already shows your currency the extension deliberately leaves the price alone. Conversion pivots through USD, so it needs a rate for both currencies; rates refresh every 12 hours and can be edited by hand under Exchange rates. If that all looks right, use Check this page — game-page prices in particular are drawn with CSS by GOG, which the extension reads specially.

What is endless scrolling, and why is it off?

When you reach the end of the 48 games on a catalog page, it appends the next page below, as the extension's own cards. To do that it asks GOG's own catalog API (catalog.gog.com) for the same list the site is already showing — the same call the site makes. It's off by default because it adds a network destination; turn it on under Catalog, wishlist & library. It only continues a list it can match to the one on screen.

What does "this pack contains games you own" use?

A bundle's own page lists its games, so reading them costs nothing. For other packs the extension asks GOG's product API once per game page, sending only the numeric product id, and remembers the answer for 30 days. You can switch it off under Catalog, wishlist & library.

Why do I have to type my purchase date for the refund timer?

GOG doesn't show a purchase date on the game page, so the 30-day countdown starts from a date you enter in the panel. No date, no countdown.

Which languages does it speak?

The tag dashboard, Advanced Options, popup and first-run wizard come in English, Hebrew (laid out right-to-left), Russian, Polish, German, French and Spanish — pick one under Interface language. What you wrote yourself (tag names, notes) is never translated. Separately, the optional Hebrew translation overlay translates gog.com's own navigation and interface. The non-English translations have not been reviewed by native speakers; tell us what reads wrong.

Does it work in Firefox, Edge, Brave or Opera?

Edge, Brave and Opera run the same build as Chrome. A Firefox variant is attached to each release; it passes the add-on linter but has not been run in a real Firefox, and folder sync isn't available there. Treat it as experimental.

Keyboard shortcuts?

Alt+G opens the popup, Alt+Shift+G switches the extension on or off, Alt+Shift+H toggles the Hebrew overlay, Ctrl/Cmd+K on gog.com opens a command palette. Optional (off by default): J/K/T on game grids and W/N/A on a game page. In the tag dashboard, Alt+↑/↓ reorders the focused tag. Type gog and Tab in the address bar to search your own library. Chrome lets you rebind the global ones at chrome://extensions/shortcuts.

How do I remove it?

Uninstall it from chrome://extensions; the browser deletes its storage. If you used folder sync, the file in your folder stays until you delete it. Advanced Options → Reset everything wipes the data without uninstalling.

Is it official? Does it cost anything?

It's an unofficial, free, open-source (MIT) extension with no ads, analytics or paid tier, and it isn't affiliated with GOG sp. z o.o. or CD Projekt S.A. If it saves you money or time you can support it on Ko-fi, Buy Me a Coffee or Patreon — entirely optional.

Where do I report a bug or ask for a feature?

On GitHub Issues. Attaching the output of Check this page makes a site-change problem much quicker to fix.
