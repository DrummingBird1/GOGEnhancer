Changelog

Every release, from the first version to today. Each one also has its own page on GitHub Releases, with the download and its own banner.

v2.9.0Current

Wishlist deals, worth-waiting verdicts, and a big testing pass

New features

  • 🔥 Wishlist deals in the popup — shows your top 3 wishlisted price drops (≥10% off each game's tracked peak), linking straight to the game.
  • "Worth waiting?" verdict on the game-page price panel — a plain-language read on whether now looks like a good time to buy.
  • Wishlist value stat + CSV export in the tag dashboard — totals the current price of every wishlisted game with tracked history.
  • Ko-fi + Buy Me a Coffee alongside Patreon — three ways to support instead of one.
  • Two more stale "v2.4" version badges fixed (onboarding wizard, options footer).

Under the hood

  • Real test suites for background.js, popup.js, options.js, onboarding.js — all four had zero coverage before. Extension-wide coverage: 23% → 55%.
  • Found and fixed two real bugs while writing those tests: a silently-dead ensureDefaults(), and a CSS rule that showed "no results" on every Advanced Options page load.
  • npm run typecheck now covers all of content/ and tags/, not just lib/.

v2.8.0

content.js / tags.js module split, plus a feature round built on top

  • ⌘K / Ctrl+K command palette — quick access to settings, the tag dashboard, and force-refreshes.
  • Wishlist-wide price alerts — get notified when any wishlisted game drops off its tracked peak price, no per-game setup needed.
  • Playing / Backlog / Finished status per game, separate from tags, filterable with status:playing.
  • Auto theme that follows your system's light/dark preference.
  • 7-language interface — English, Hebrew, Russian, Polish, German, French, Spanish.
  • Search box in Advanced Options; undoable toast for tag deletion; design & reduced-motion polish.
  • Under the hood: content.js and tags.js split from two giant files into a real module structure — the single riskiest refactor in the project's history, shipped as its own isolated, fully re-tested release.
View release →
v2.7.0

Infrastructure audit: security, testing, CI/CD, architecture

  • Storage writes now surface failures loudly instead of silently resolving; settings import runs the same migration pass a real upgrade would.
  • GitHub Actions pinned to commit SHAs (supply-chain hardening); npm audit added to CI.
  • Test suite grew 44 → 118 tests, including direct regression coverage for the card-badge placement "hot zone."
  • New lib/genres.js, # @ts-check + JSDoc typing for lib/.
  • Price-history storage now enforces a 2 MB total-size budget, evicting least-recently-updated games rather than growing unbounded.
